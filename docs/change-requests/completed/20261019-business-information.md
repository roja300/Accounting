# Create Invoices Persistence

*Date: 19/10/2026* <br>
*Author: Rojaware*<br>

## Overview

A new profile page for configuring a businesses information and settings. This is going to be used as part of the invoice that gets generated.

### Functional Specification (FS)

1. The system should enable configuring a business.
2. The system should provide a profile icon on the right side of the navbar.
3. The system should enable setting what would be required for a UK invoice.
4. The system should enable configuring different clients/customers.
5. Each customer should be able to be assigned a name, address, contact information, etc. and anything required to be provided in an invoice to a digital freelancers customer.
6. Clients/customers should be able to be created here.
7. The system should NOT enable users to create new clients when creating a new work record.
8. The system should prevent a user from creating a new work record if no customer is configured.

### Non-functional Specification (NFS)

1. The UI should be aligned with the rest of the application.
2. Configuration should be stored in the database as a new table. Likely only one per business.
