## Overview

Disabling work records in the application. 

### Functional Specification (FS)

1. The system should allow viewing work records.
2. The system should provide a brief overview of each work record.
3. The system should display each work record as a card, not as a table.
4. The system should paginate all work records so they are not loaded at once.
5. The system should provide options to filter work records by,
   1. date before,
   2. date after,
   3. project,
   4. client,
   5. searching description.
6. The work record should have a popup menu with options for editing and deleting. These will be disabled for now.

### Non-functional Specification (NFS)

1. The same patterns should be followed as with persisted work records.
